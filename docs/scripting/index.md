# Scripting reference

This part documents what scripts can do. Where each kind of script goes in a
pack, and when it runs, is in [Scripting](../packs/scripting.md) under Game
packs.

- **[Lua API](lua/index.md)**: the functions and tables the engine gives Lua
  scripts: hooks, screens, the menus' GUI and the enemies.
- **[Room scripts](room/index.md)**: the `.akscr` language the rooms are
  scripted in, with a page per instruction for [RE 1](room/re1/index.md) and
  [RE 2](room/re2/index.md).
